# 演習 – Codespaces と Visual Studio Code でコードを書く

GitHub Codespaces と Visual Studio Code を使い、クラウド上でコードを編集して実行します。Codespaces は必要なツールを備え、設定を変更できる開発環境です。手元の端末に開発環境を構築せずに作業できます。

この演習で学ぶこと

- Codespace（クラウド上の開発環境）を作成し、設定する
- ブラウザー版 Visual Studio Code を使う
- Codespaces でコードを編集して実行する
- 開発環境を管理し、設定を変更する
- クラウド上で開発する利点を理解する

所要時間の目安は **30〜45分** です。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- インターネットに接続できるブラウザー。
- コードの読み書きや IDE（統合開発環境）の使い方を知っていると進めやすくなります。初めてでも取り組めます。

## GitHub で演習を進める

演習リポジトリを作成したあとの詳しい操作は、[演習リポジトリの日本語手順](Exercise-Repositories/code-with-codespaces/README.md) で確認できます。

GitHub Skills の課題に取り組みながら、Codespace の作り方と使い方を学びます。

> **注**　Codespace を作成してコードを変更し、クラウド上の開発環境で作業する流れを体験します。

次の手順で進めます。

1. GitHub にサインインし、[日本語版テンプレートから演習を作成する](https://github.com/new?template_owner=ctct-edu&template_name=code-with-codespaces&owner=%40me&name=skills-code-with-codespaces&description=Exercise:+Code+with+Codespaces&visibility=public) を開きます。

1. 作成画面上部の **Owner** で自分の GitHub アカウントを選びます。その横の **Repository name** に `skills-code-with-codespaces` が入力されていることを確認します。公開範囲を確認し、画面下部の **Create repository** を選びます。

   > 作成後は、ページ左上の所有者名が自分のアカウントになっていることを確認します。20秒ほど待って再読み込みし、**Code** タブのファイル一覧の下にある README を確認します。**Go to Exercise** が出たらクリックします。上部の **Issues** タブから演習 Issue を開くこともできます。

   > **注**　自分のアカウントにコピーを作成したら、最初の課題が用意されるまで20秒ほど待ってページを再読み込みします。

1. 自分のコピーの README から演習 Issue を開き、日本語のステップ案内に従います。

   - 自分のリポジトリ用の Codespace を作成する
   - Codespace の画面を操作して機能を確認する
   - Visual Studio Code のエディターでコードを変更する
   - 統合ターミナルでコードを実行し、テストする
   - Codespace から変更をコミットし、GitHub にプッシュする
   - Codespace を管理し、リソースの利用状況を把握する

1. 画面に表示される案内に従い、順に課題を進めます。

   > **注**　Codespaces には、拡張機能、ターミナル、デバッグ機能を備えた開発環境が用意されています。

1. すべての課題を終えると、開発作業に Codespaces を取り入れる流れが分かります。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- Codespace を作成して起動できる
- ブラウザー版 Visual Studio Code を使える
- クラウド上の環境でコードを編集・実行できる
- Codespace の設定を変更できる
- Codespaces と手元の開発環境をどう使い分けるか説明できる
- Codespace の利用リソースを管理できる
- 開発の流れに Codespaces を組み込める

「Codespaces と Visual Studio Code でコードを書く」の演習はこれで完了です。
