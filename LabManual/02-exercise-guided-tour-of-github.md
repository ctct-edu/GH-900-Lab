# 演習 – GitHub の基本操作を体験する

GitHub で共同作業を始めるための基本を、1時間ほどで体験します。リポジトリ、ブランチ、コミット、プルリクエストを実際に使ってみましょう。

この演習で学ぶこと

- ブランチを作成する
- ファイルの変更をコミットする
- プルリクエストを作成する
- プルリクエストをマージする

所要時間の目安は **60分** です。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- インターネットに接続できるブラウザー。

## GitHub で演習を進める

演習リポジトリを作成したあとの詳しい操作は、[演習リポジトリの日本語手順](Exercise-Repositories/introduction-to-github/README.md) で確認できます。

案内に沿って課題に取り組み、GitHub のリポジトリを操作する基本を学びます。

> **注**　GitHub Skills の演習です。リポジトリに表示される手順を進めると、操作の結果が自動で確認されます。

次の手順で進めます。

1. 講師から案内された日本語版の演習リポジトリをブラウザーで開きます。[日本語版テンプレートの内容](Exercise-Repositories/introduction-to-github/README.md)も参照できます。

1. 演習ページの **Use this template**（このテンプレートを使用）を選び、自分の GitHub アカウントに演習のコピーを作成します。

   > **注**　自分のアカウントにコピーを作成したら、最初の課題が用意されるまで20秒ほど待ってページを再読み込みします。

1. リポジトリの README に従って、すべての課題に取り組みます。

   > **注**　ブランチの作成、ファイルのコミット、プルリクエストの作成とマージを順に行います。各操作の結果は自動で確認されます。

1. README や、演習で作られる Issue・プルリクエストの案内に沿って、各ステップを進めます。

1. すべての課題を終えると、プロフィール用の README として使える短い Markdown ファイルが完成します。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- リポジトリ、ブランチ、コミット、プルリクエストの役割を説明できる
- リポジトリ内のブランチを作成・管理できる
- 作業内容をコミットとして記録できる
- 変更を提案するためのプルリクエストを作成できる
- プルリクエストを確認してマージできる
- ブラウザーで GitHub の基本操作ができる

「GitHub の基本操作を体験する」の演習はこれで完了です。
