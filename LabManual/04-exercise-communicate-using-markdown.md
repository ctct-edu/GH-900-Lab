# 演習 – Markdown で分かりやすく伝える

Markdown は、簡単な記号で文章の見た目を整える書き方です。この演習では、GitHub で共同作業をする際に、Issue（課題）やプルリクエストで情報を整理して伝えるための書き方を学びます。

この演習で学ぶこと

- 見出しで内容を整理する
- 画像で説明を分かりやすくする
- コード例を掲載する
- タスクリストを作成して進み具合を確認する
- GitHub で Markdown を活用する

所要時間の目安は **60分** です。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- プルリクエストの基本操作。初めての方は、先に [GitHub の入門演習](02-exercise-guided-tour-of-github.md) に取り組むと進めやすくなります。
- インターネットに接続できるブラウザー。

## GitHub で演習を進める

演習リポジトリを作成したあとの詳しい操作は、[演習リポジトリの日本語手順](Exercise-Repositories/communicate-using-markdown/README.md) で確認できます。

GitHub Skills の課題に沿って文章を編集し、Markdown で書式を整えます。

> **注**　プレーンテキストのファイルを Markdown で整えます。作成したファイルは、GitHub Pages で自分のサイトを作る際にも使えます。

次の手順で進めます。

1. GitHub にサインインし、[日本語版の演習リポジトリ](https://github.com/ctct-edu/communicate-using-markdown) を開きます。

1. 演習ページの **Use this template**（このテンプレートを使用）を選び、自分の GitHub アカウントに演習のコピーを作成します。

   > **注**　自分のアカウントにコピーを作成したら、最初の課題が用意されるまで20秒ほど待ってページを再読み込みします。

1. リポジトリの README に従い、次の課題に取り組みます。

   - 見出しを追加し、内容のまとまりと階層を分かりやすくする
   - 画像を追加し、内容を視覚的に伝える
   - コードブロックを使ってコード例を載せる
   - タスクリストを作り、進み具合を確認する
   - プルリクエストをマージして演習を終える

1. Issue やプルリクエストに表示される案内に従い、順に課題を進めます。

   > **注**　演習では Markdown の書式が自動で確認され、次の操作が案内されます。

1. すべての課題を終えると、さまざまな書式を使った Markdown ファイルが完成します。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- 見出しで情報を階層的に整理できる
- 箇条書きや番号付きリストを作成できる
- ドキュメントに画像を載せられる
- プログラミング言語に合わせてコードブロックを整形できる
- チェックボックス付きのタスクリストを作成できる
- 太字、斜体、リンクなどの基本書式を使える
- GitHub の Issue やプルリクエストで Markdown を使える
- GitHub で技術的な内容を分かりやすく伝えられる

「Markdown で分かりやすく伝える」の演習はこれで完了です。
