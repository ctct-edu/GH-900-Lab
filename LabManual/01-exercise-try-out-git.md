# 演習 – Git を使ってみる

実際に操作しながら、Git の基本を学びます。変更履歴を管理する仕組みから、コミットやブランチを使った共同作業の流れまで、一つずつ確認します。

この演習で学ぶこと

- 変更履歴を管理する考え方を理解する
- Git でコミットの作成者として記録される名前とメールアドレスを設定する
- リポジトリを作成し、変更をコミットする
- リポジトリの変更履歴を調べる
- ブランチを使う
- 共同作業の基本的な流れを体験する

研修での所要時間の目安は **45〜60分** です。初めて操作する受講者向けの見積もりです。Codespace の初回起動と6ステップの自動判定を含みます。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- インターネットに接続できるブラウザー。

## GitHub で演習を進める

演習リポジトリを作成したあとの詳しい操作は、[演習リポジトリの日本語手順](Exercise-Repositories/introduction-to-git/README.md) で確認できます。

GitHub 上の案内に沿って課題に取り組み、Git の基本を身に付けます。

> **注**　演習は GitHub 上で進めます。リポジトリに表示される手順を順番に実行してください。

次の手順で進めます。

> 演習 Issue に次のステップが表示されてから、そのステップの操作を行います。案内が出た直後は **Actions** タブで前の実行が完了したことも確認してください。今回の検証では1回の判定に数十秒かかりました。

1. GitHub にサインインし、[日本語版テンプレートから演習を作成する](https://github.com/new?template_owner=ctct-edu&template_name=introduction-to-git&owner=%40me&name=skills-introduction-to-git&description=Exercise:+Introduction+to+Git&visibility=public) を開きます。

1. 作成画面上部の **Owner** で自分の GitHub アカウントを選びます。その横の **Repository name** に `skills-introduction-to-git` が入力されていることを確認します。公開範囲を確認し、画面下部の **Create repository** を選びます。

   > 作成後は、ページ左上の所有者名が自分のアカウントになっていることを確認します。20秒ほど待って再読み込みし、**Code** タブのファイル一覧の下にある README を確認します。**Go to Exercise** が出たらクリックします。上部の **Issues** タブから演習 Issue を開くこともできます。

1. 自分のコピーの README から演習 Issue を開き、日本語のステップ案内に従います。

   > **注**　演習用ワークフローのファイルはそのまま使います。変更すると、操作の確認やフィードバックが正しく動かなくなることがあります。 自動判定や採点にも影響することがあります。

1. 各ステップで表示される案内に沿って操作します。

1. すべての課題を終えれば、演習は完了です。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- Git のバージョン管理の基本を説明できる
- Git の作成者情報を設定できる
- Git リポジトリを作成して使える
- コミットを作り、履歴を確認できる
- ブランチを使える
- Git を使った共同作業の基本的な流れが分かる

「Git を使ってみる」の演習はこれで完了です。
