# 演習 – プルリクエストをレビューする

GitHub でプルリクエストをレビューします。コードレビューはソフトウェア開発の大切な工程で、GitHub ではプルリクエストを使って変更内容を共有し、確認できます。変更の確認、改善につながる意見の伝え方、承認の進め方を学びます。

この演習で学ぶこと

- レビューの流れを理解する
- コードの変更箇所を確認する
- コメントや修正案を残す
- 変更を提出した人に修正を依頼する
- プルリクエストを承認する
- GitHub のレビュー機能を使う

所要時間の目安は **30〜45分** です。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- プルリクエストとブランチの基本を理解していること。
- インターネットに接続できるブラウザー。

## GitHub で演習を進める

演習リポジトリを作成したあとの詳しい操作は、[演習リポジトリの日本語手順](Exercise-Repositories/review-pull-requests/README.md) で確認できます。

GitHub Skills の課題に沿って、プルリクエストをレビューする一連の流れを体験します。

> **注**　コードにコメントを付けるなど、GitHub のレビュー機能を実際に使います。

次の手順で進めます。

1. GitHub にサインインし、[日本語版の演習リポジトリ](https://github.com/ctct-edu/review-pull-requests) を開きます。

1. 演習ページの **Use this template**（このテンプレートを使用）を選び、自分の GitHub アカウントに演習のコピーを作成します。

   > **注**　自分のアカウントにコピーを作成したら、最初の課題が用意されるまで20秒ほど待ってページを再読み込みします。

1. リポジトリの README に従い、次の課題に取り組みます。

   - レビューの流れと重要性を理解する
   - プルリクエストでコードの変更箇所を確認する
   - 変更された行にコメントを付け、具体的な意見を伝える
   - 変更全体の評価をレビューの概要にまとめる
   - 改善が必要な場合に修正を依頼する
   - 基準を満たしたプルリクエストを承認する
   - 修正提案機能で具体的な編集案を提示する

1. プルリクエストに表示される案内に従い、順に課題を進めます。

   > **注**　さまざまな場面を通して、コメント、修正依頼、承認をどう使い分けるかを学びます。

1. すべての課題を終えると、プルリクエストをレビューする一連の操作を行えるようになります。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- プルリクエスト画面の各項目を理解し、目的の情報を見つけられる
- コードの変更を効果的に確認できる
- 改善につながる具体的な意見を伝えられる
- 行単位のコメントと全体へのコメントを使い分けられる
- 必要に応じて修正を依頼できる
- 基準を満たしたプルリクエストを承認できる
- 修正提案機能で具体的な編集案を提示できる
- プルリクエストをレビューする際の推奨事項を説明できる
- レビューを通してチームで共同作業できる

「プルリクエストをレビューする」の演習はこれで完了です。
