# 演習 – リポジトリ内の作業を関連付ける

GitHub リポジトリ内の作業を関連付ける方法を学びます。Issue（課題）、プルリクエスト、コミットをリンクでつなぐと、どの作業がどの変更につながったかを追いかけやすくなり、プロジェクトの進み具合も把握できます。

この演習で学ぶこと

- Issue とプルリクエストをリンクする
- 会話の中でコミットを参照する
- キーワードで Issue を自動的に閉じる
- 作業項目同士を関連付ける
- 関連項目をたどって作業の状況を把握する
- リポジトリ内の作業を整理し、必要な項目を見つける

所要時間の目安は **30分** です。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- Issue とプルリクエストの基本を理解していること。
- インターネットに接続できるブラウザー。

## GitHub で演習を進める

演習リポジトリを作成したあとの詳しい操作は、[演習リポジトリの日本語手順](Exercise-Repositories/connect-the-dots/README.md) で確認できます。

GitHub Skills の課題に沿って、作業項目の関連付けや参照の方法を学びます。

> **注**　Issue をプルリクエストに関連付けたり、Issue を自動で閉じるキーワードを使ったりしながら、作業を整理します。

次の手順で進めます。

1. GitHub にサインインし、[日本語版テンプレートから演習を作成する](https://github.com/new?template_owner=ctct-edu&template_name=connect-the-dots&owner=%40me&name=skills-connect-the-dots&description=My+clone+repository&visibility=public) を開きます。

1. **Repository name** に `skills-connect-the-dots` が入力されていることを確認し、**Owner** と公開範囲を選んで **Create repository** を選びます。

   > **注**　自分のアカウントにコピーを作成したら、最初の課題が用意されるまで20秒ほど待ってページを再読み込みします。

1. リポジトリの README に従い、次の課題に取り組みます。

   - 作業を追跡するために Issue を作成する
   - プルリクエストやコメントから Issue を参照する
   - `fixes #1` や `closes #2` など、Issue を閉じるキーワードを使う
   - プルリクエストを特定の Issue にリンクする
   - プルリクエストがマージされたときに Issue が自動で閉じる仕組みを理解する
   - 異なる Issue とプルリクエストを相互に参照する
   - リンクをたどって関連する項目を見つける

1. 画面に表示される案内に従い、順に課題を進めます。

   > **注**　作業を関連付けると、変更の経緯をたどりやすくなり、プロジェクトの管理にも役立ちます。

1. すべての課題を終えると、GitHub リポジトリ内の作業を整理し、関連付ける方法が分かります。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- Issue を作成し、必要な場所から参照できる
- プルリクエストを関連する Issue にリンクできる
- キーワードを使って Issue を自動的に閉じられる
- 項目同士の関係をリンクからたどれる
- 関連する項目から作業の状況を把握できる
- プロジェクト内で作業と変更のつながりを追跡できる
- 関連項目への参照を活用してプロジェクトのドキュメントを作成できる
- リポジトリ内の作業を効率よく整理できる

「リポジトリ内の作業を関連付ける」の演習はこれで完了です。
