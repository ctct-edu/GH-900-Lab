# 演習 – GitHub Copilot と VS Code で AI のコード候補を使う

Visual Studio Code で GitHub Copilot を使い、AI が示すコード候補を開発に取り入れます。Copilot は、編集中のコードや指示に応じて、1行のコードから関数全体まで提案する AI アシスタントです。

この演習で学ぶこと

- VS Code で GitHub Copilot をインストールして設定する
- GitHub Copilot でコードを補完する
- Copilot の候補を採用したり、手直ししたりする
- 目的に合う候補を得るための指示（プロンプト）を書く
- どのようなときに候補を採用できるか判断する
- 開発作業に AI の支援を取り入れる

所要時間の目安は **30〜45分** です。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- GitHub Copilot を利用できること。原文ではサブスクリプションまたは試用版が必要と案内されています。
- 基本的なプログラミングの知識。言語は問いません。
- インターネットに接続できるブラウザー。

## GitHub で演習を進める

演習リポジトリを作成したあとの詳しい操作は、[演習リポジトリの日本語手順](Exercise-Repositories/getting-started-with-github-copilot/README.md) で確認できます。

GitHub Copilot の導入から実際の使い方までを、操作しながら学びます。

> **注**　Microsoft Learn から始める演習です。GitHub Codespaces 内で Copilot を使えるようにし、指示を出してコード候補を得る方法や、AI の提案を開発に取り入れる際の推奨事項を学びます。

次の手順で進めます。

1. GitHub にサインインし、[日本語版の演習リポジトリ](https://github.com/ctct-edu/getting-started-with-github-copilot) を開きます。

1. **Use this template**（このテンプレートを使用）を選び、自分のアカウントにリポジトリのコピーを作成します。

   > **注**　非公開リポジトリでは GitHub Actions の利用枠を消費するため、原文では公開リポジトリが推奨されています。作成後は20秒ほど待ってページを再読み込みします。

1. リポジトリの README に従って、次の課題に取り組みます。

   - GitHub Codespaces を使って GitHub Copilot をインストールする
   - Copilot に指示を出してコード候補を得る
   - Copilot のコード候補を採用する
   - 入力中の行に表示される候補（インライン）や、複数行の候補を使う
   - AI の支援を開発に取り入れる際の推奨事項を学ぶ
   - Copilot の候補を採用できるか、自分で判断する

1. README に表示される案内に従い、各ステップを進めます。

   > **注**　演習用ワークフローのファイルはそのまま使います。変更すると、操作の確認やフィードバックが正しく動かなくなることがあります。

1. すべての課題を終えたら、Microsoft Learn のモジュールに戻り、知識チェックに取り組んで修了バッジを取得します。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- 開発環境で GitHub Copilot をインストール・設定できる
- GitHub Copilot からコード候補を得られる
- 候補を採用、修正、却下する判断ができる
- 目的に合った候補を得るためにプロンプトを書ける
- AI によるコーディング支援でできることと限界を説明できる
- 開発の流れに GitHub Copilot を組み込める
- AI を使って開発効率とコードの品質を高められる
- AI の支援を使った開発の推奨事項を実践できる

「GitHub Copilot と VS Code で AI のコード候補を使う」の演習はこれで完了です。
