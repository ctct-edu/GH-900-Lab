# 演習 – 初めてのプルリクエストを作成する

オープンソースプロジェクトへの初めての貢献を体験します。GitHub 上に自分のコピーを作り、端末に複製して編集し、プルリクエストで変更を提案するまでを順に進めます。

この演習で学ぶこと

- リポジトリをフォークする
- リポジトリを手元の端末にクローンする
- ブランチを作成する
- ファイルを編集してコミットする
- コミットを GitHub にプッシュする
- プルリクエストを作成する
- 変更を提出し、レビューを受けられる状態にする

所要時間の目安は **30分** です。

## 始める前に

- GitHub アカウント。アカウントを持っていない方は、受講前に [新規登録](https://github.com/join) してください。手順は [GitHub アカウントの作成](https://docs.github.com/get-started/quickstart/creating-an-account-on-github) を参照してください。
- 受講端末にインストール済みの Git。未導入の場合は [Git のセットアップ](https://docs.github.com/en/get-started/quickstart/set-up-git) を参照してください。
- コードを編集できるエディター（Visual Studio Code など）。
- インターネットに接続できるブラウザー。

## GitHub で演習を進める

リポジトリの操作を日本語で確認するには、[First Contributions プロジェクトの日本語手順](https://github.com/firstcontributions/first-contributions/blob/main/docs/translations/README.ja.md) を開きます。

貢献者一覧に名前を追加して、オープンソースプロジェクトへの初めての貢献を体験します。

> **注**　この演習では、5万人以上の初めての貢献を支援してきた「first-contributions」リポジトリを使います。実際に操作しながら、貢献の一連の流れを体験できます。

次の手順で進めます。

1. ブラウザーで [演習リポジトリ](https://github.com/firstcontributions/first-contributions) を開きます。

1. README の詳しい手順を読み、次の操作を行います。

   - ページ上部の **Fork** を選び、GitHub 上の自分のアカウントにリポジトリのコピーを作成します。
   - Git で自分のフォークを端末にクローン（複製）します。
   - 変更を加えるためのブランチを作成します。
   - `Contributors.md` に自分の名前を追加します。
   - 何を変更したかが伝わるメッセージを付けてコミットします。
   - コミットした変更を GitHub 上の自分のフォークにプッシュします。
   - 元のプロジェクトに変更を提出するため、プルリクエストを作成します。

1. リポジトリの説明と画面例を見ながら、各ステップを進めます。

   > **注**　コマンドラインに不慣れな場合は、GitHub Desktop や Visual Studio Code など、画面上で操作するツールのチュートリアルも用意されています。

1. プルリクエストを提出すると、プロジェクトのメンテナーによるレビューとマージの対象になります。

1. プルリクエストがマージされたら、通知メールで結果を確認できます。これで初めての貢献が完了です。

## 演習の振り返り

この演習を終えると、次のことができるようになります。

- GitHub 上のリポジトリをフォークできる
- リポジトリを受講端末にクローンできる
- 作業用ブランチを作成できる
- 変更の内容が伝わるメッセージを付けてコミットできる
- 変更を GitHub にプッシュできる
- プルリクエストを作成して提出できる
- 変更の準備から提出までの流れを説明できる
- オープンソースプロジェクトに貢献できる

初めてのプルリクエストを作成し、オープンソースへの貢献を体験できました。

---

**研修での補足**　公開される貢献者一覧には、公開してよい表示名を使ってください。研修内ではプルリクエストの提出までを到達点とします。操作の詳細はプロジェクトの日本語版も参照できます。[First Contributions の日本語手順](https://github.com/firstcontributions/first-contributions/blob/main/docs/translations/README.ja.md)
